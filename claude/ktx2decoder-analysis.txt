   Imported by: index.ts, legacy/legacy.ts

   BUG FOUND - Line 45 (options merge order):
     `const finalOptions = { ...options, ...KTX2Decoder.DefaultDecoderOptions };`
     The spread order is reversed. DefaultDecoderOptions properties always override
     user-provided options, which is backwards. "Default" options should be the
     fallback, not the override. User-passed `options` should take precedence.
     Fix: `{ ...KTX2Decoder.DefaultDecoderOptions, ...options }`

   BUG FOUND - Line 50 (typo in error message):
     `throw new Error("Invalid KT2 file: wrong signature");`
     Should be "KTX2" not "KT2".

8. zstddec.ts (Zstandard decompression)
------------------------------------------------------------
   Imports: transcoder (for GetWasmUrl)
   Imported by: ktx2Decoder.ts

   BUG FOUND - Line 59 (Node.js fallback uses undefined `fetch`):
     The else branch (lines 55-60) executes when `typeof fetch === "undefined"`,
     meaning fetch is NOT available. Yet it calls:
       `WebAssembly.instantiateStreaming(fetch(ZSTDDecoder.WasmModuleURL), ...)`
     This will throw a ReferenceError at runtime in environments without fetch.

   TYPE IMPROVEMENT - Line 9 (DecoderExports interface):
     `memory: Uint8Array` should be `memory: WebAssembly.Memory`.
     WASM modules export `WebAssembly.Memory` objects, not `Uint8Array`.
     The code works because both types have a `.buffer` property, but the type
     is inaccurate and could confuse readers.
