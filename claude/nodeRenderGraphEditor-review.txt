1. ARCHITECTURE OVERVIEW
================================================================================

The Node Render Graph Editor (NRGE) is a visual node-based editor for
constructing Babylon.js render graphs. It follows the same architecture pattern
as the Node Material Editor (NME), with a shared UI component library
(shared-ui-components) providing the graph canvas, node system, and property
infrastructure.

Key architectural layers:
- Entry point: index.ts -> nodeRenderGraphEditor.ts (NodeRenderGraphEditor.Show)
- Core state: globalState.ts (GlobalState class, central state management)
- Main UI: graphEditor.tsx (GraphEditor React component)
- Serialization: serializationTools.ts
- Block creation: blockTools.ts (factory + color mapping)
- Graph system: graphSystem/ (node data, port data, display managers,
  property components, registration functions)
- Preview: components/preview/ (preview manager, mesh controls, area)
- Property panel: components/propertyTab/
- Shared components: sharedComponents/ (reusable UI widgets)

3. ISSUES FOUND
================================================================================

--- BUG #1: Wrong title in frameNodePortPropertyComponent.tsx (line 58) ---
Severity: Medium (Incorrect UI text)
The title says "NODE MATERIAL EDITOR" but should say "NODE RENDER GRAPH EDITOR".
This is a copy-paste error from the Node Material Editor codebase.

--- BUG #2: Wrong title in framePropertyComponent.tsx (line 53) ---
Severity: Medium (Incorrect UI text)
Same copy-paste error: "NODE MATERIAL EDITOR" should be "NODE RENDER GRAPH EDITOR".

--- BUG #3: Alpha channel display bug in textureLineComponent.tsx (lines 138-141) ---
Severity: High (Functional bug)
When displaying the alpha channel, the code reads `data[i + 2]` (blue channel)
instead of `data[i + 3]` (alpha channel). Then it zeros `data[i + 2]` (blue)
instead of setting `data[i + 3]` to 255 (opaque alpha for display). This means
the "A" button in the texture preview displays the blue channel as grayscale
rather than the actual alpha channel.

--- BUG #4: Duplicate _previewManager disposal in graphEditor.tsx (lines 199-202) ---
Severity: Low (Dead code)
In componentWillUnmount(), _previewManager is checked, disposed, and set to null
at lines 187-190. Then the exact same check/dispose/null is repeated at lines
199-202. The second block is unreachable dead code since _previewManager was
already set to null.

--- BUG #5: Memory leak in logComponent.tsx ---
Severity: Medium (Memory leak)
componentDidMount() adds an observer to onLogRequiredObservable but there is no
componentWillUnmount() to remove it. When the component unmounts, the observer
remains, causing a memory leak and potential errors if the observable fires
after unmount.

--- BUG #6: Duplicate nested div with same id in previewAreaComponent.tsx ---
Severity: Low (Invalid HTML, potential CSS/JS issues)
Lines 58 and 60 both render `<div id="preview-config-bar">`, creating a nested
duplicate. The outer div is unnecessary wrapper that creates invalid HTML
(duplicate IDs).

--- BUG #7: Block registration nested in wrong loop in nodeListComponent.tsx ---
Severity: Low (Performance - redundant work)
Lines 292-315 (the NodeLedger registration loop and NameFormatter assignment)
are inside the outer `for (const key in allBlocks)` loop that builds blockMenu.
This means ALL blocks get re-registered and NameFormatter gets re-assigned on
every iteration of the outer loop. This code should run once, outside the loop.

--- BUG #8: Division by zero in textureMemoryUsagePropertyTabComponent.tsx ---
Severity: Low (Potential NaN display)
Line 33 computes `Math.round((100 * (totalSize - optimisedSize)) / totalSize)`
before the JSX guard `{totalSize !== 0 && ...}`. If totalSize is 0, the saving
variable is NaN. While the JSX won't display it, the computation still runs.

--- IMPROVEMENT #1: Deprecated substr() in draggableLineWithButtonComponent.tsx ---
Severity: Low (Deprecation warning)
Line 36 uses `String.prototype.substr()` which is deprecated. Should use
`substring()` or `slice()` instead.

--- IMPROVEMENT #2: Typos in graphEditor.tsx ---
Severity: Low (Comments/strings)
- Line 380: "probabaly" should be "probably"
- Line 387: "isprobably" should be "is probably"
- Lines 399, 451: "graphes" should be "graphs"

--- IMPROVEMENT #3: Unused observer in previewManager.ts ---
Severity: Low (Dead code)
_onUpdateRequiredObserver is declared (line 45) but never assigned a value.
The dispose() method tries to remove it (line 589), but it's always null so
the removal is a no-op.
